# Legere

Legere 是一款 Windows 本地 PDF 阅读器。把存放 PDF 的文件夹添加为文献库，就能在弧形书架上翻书，也能凭记得的一句话找回原文所在的那一页。PDF 留在原目录，搜索索引、书签和阅读进度都保存在本机。

## 阅读特色

- **可以转动的书架。** 用滚轮、拖动或方向键翻过书脊，点中央书名打开选中的书。每次切书，主页都会随机画出一幅新的草木线描。想要素净的书架，可以在设置中关闭花纹。
- **从正在读的地方开始找。** 按 `Ctrl+F` 从当前阅读位置搜索，第一处命中出现后即可查看，再逐处向前或向后跳转。同页重复出现的词、跨行的短语和行末断开的单词都能定位并高亮。
- **凭正文找回一本书。** 只记得内容时，按 `Ctrl+K` 搜索整个文献库中已索引的正文，点结果直达对应页。全文检索适用于带文本层的 PDF。
- **放大看图表和扫描件。** 阅读大幅地图、宽表或高清扫描页时，Legere 会优先绘制视口内的图块。缩放过程中会暂时保留原有画面，再逐块补清细节。
- **按自己的习惯阅读。** 支持连续阅读和单页阅读，可选浅色、深色或纸感主题。界面字号与 PDF 缩放可分别调整。下次打开时，从主页底部的「上次阅读」就能接着读。

## 安装与使用

从 [GitHub Releases](https://github.com/PinelliaCSU/legere/releases/latest) 下载 Windows x64 安装包，选择 EXE 或 MSI 均可。运行需要 Microsoft Edge WebView2 Runtime。

首次打开后，进入 **文献库 → 添加文献库**，选择 PDF 所在的文件夹。Legere 会扫描其中的子文件夹，之后即可离线阅读和检索。
