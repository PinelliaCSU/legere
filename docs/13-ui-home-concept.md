# 13 · 主页空间概念（用户设计，契约层）

> **来源**：`design_pictures/主页示意.png`（标题：主页空间概念；页脚注：概念结构示意，非最终视觉设计）。
> **状态**：本文件固化**空间模型 / 数据契约 / 交互状态机 / 性能边界**；一切**视觉与手感**决策标注为「【待你确认】」，模块 Agent 不得自行拍板。
> **归属模块**：M14 workspace-shell（`<HomeSpace/>`）。

## 1. 用户设计的记录（原样，不可改写）

示意图中的事实（读图所得，逐条对应）：

1. 书籍以**书脊**形态沿一个**圆周**排布，每根书脊的长轴沿**半径方向**（大致指向圆心/背离圆心），并非全部竖直。
2. 圆心左侧是一段**实线粗圆环**，圆内标注「可见书籍区域」——位于该弧段上的书脊被完整渲染（图例：可见 = 书脊渲染与交互）。
3. 圆心右侧是一个**虚线圆**，圆内标注「隐藏区域」——图例：隐藏 = **不渲染书籍信息**。
4. 顶部有一条**带箭头的弧线**，从可见区指向隐藏区，表示**旋转方向**：书脊随环转动进出可见弧段。
5. 页脚明确：这是**概念结构示意，非最终视觉设计**。
6. 书脊颜色为有限的几种（橄榄绿、棕、紫、沙黄、灰绿等），说明**取色以少量预设色板为主**，而不是逐本封面取色（封面取色作为可选增强，见 §7）。

## 2. 空间模型（实现契约）

```text
                    环中心 c = (cx, cy)
                                  ▲ 书脊长轴沿半径方向
                                  │
        ┌──────── 可见弧段 visibleArc ────────┐
        │   θ_i = base + i·Δ , Δ = 360°/N      │
        │   位置 p_i = c + R·(cos θ_i, sin θ_i)│
        │   旋转 rot_i = θ_i + 90°             │
        └──────────────────────────────────────┘
                    隐藏弧段：角度存在，DOM 不创建
```

参数表（**结构参数冻结，数值全部待确认**）：

| 参数 | 含义 | 契约 | 数值 |
|---|---|---|---|
| `N` | 参与环排布的书目数量 | 由数据源决定，不设上限（超出可见弧的书不挂载） | 运行时 |
| `R` | 环半径（px） | `R = 0.34 × min(vw, vh)`（不做额外 clamp，窄窗口自然变小） | **0.34（D01 已定）** |
| `c` | 环心 | 相对视口中心的偏移 | **dx = 0，dy = -4% 视口高（D01 已定）** |
| `Δ` | 相邻书脊角距 | `Δ = 360° / max(N, 12)`（少书时不挤在一起） | **下限 12（沿用）** |
| `visibleArc` | 可见弧角度 | 只有 `|normalize(θ_i - base)| ≤ visibleArc/2` 的书挂载 | **200°（D02 已定）** |
| `spineH` | 书脊长度 | `spineH = 0.42 × R` | **0.42（D03 已定）** |
| `spineW` | 书脊宽度 | 固定 28px，不随笔数/窗口变化 | **28px（D03 已定）** |
| 深度映射 | 远近感 | `t = (sin θ_i + 1)/2`；`scale = lerp(0.86, 1, t)`；`opacity = lerp(0.55, 1, t)`；`zIndex = round(t×1000)` | **sMin 0.86 / oMin 0.55，不加模糊与描边（D07 已定）** |
| 层叠 | 相邻书脊在前景处重叠（图中可见两根书脊重叠） | 允许压盖：靠前的压住靠后的，`zIndex` 由深度决定；不加分离描边、不做最小角距避让 | **允许压盖（D08 已定）** |

**绝对约束**（违反即缺陷）：

1. 隐藏弧段内的书**不生成任何 DOM 节点**（不是 `display:none`、不是 `visibility:hidden`、不是 `opacity:0`），因此也不可能被 Tab 聚焦或被读屏软件读到。
2. 旋转是**唯一**驱动书脊进出的机制；不允许"分页"式整体替换布局。
3. 布局只用 `transform`（`translate3d` + `rotate` + `scale`）与 `opacity`，不触发布局回流。

## 3. 交互状态机

```text
      ┌──────────┐  拖拽/滚轮/方向键   ┌──────────┐
      │  idle    │ ─────────────────▶ │ rotating │
      └──────────┘                    └──────────┘
           ▲                               │ 松开/惯性耗尽
           │  无惯性                       ▼
           └──────────────────────────  idle(settled)
                                          │ 点击书脊 / Enter
                                          ▼
                                     focused(选中某书)
                                          │ 再次点击 / Enter / 双击
                                          ▼
                                   opening(进入阅读器过渡)
                                          │ 过渡结束
                                          ▼
                                     route = reader
```

| 交互 | 行为 | 状态 |
|---|---|---|
| 水平拖拽 | `ringRotation += dx × dragGain`；松手按速度给惯性并指数衰减 | rotating |
| 鼠标滚轮 | **旋转转盘，与拖拽同轴**（一格约 12°；不缩放、不切换焦点） | rotating |
| `←` / `→` | 旋转一格（`Δ`），并把焦点书移到可见弧中央 | focused |
| `Enter` | 打开当前聚焦书 | opening |
| `点击书脊` | 把该书旋转到中央并聚焦 | focused |
| `点击空白` | 取消聚焦 | idle |
| `Esc` | 从阅读器返回主页（若在 reader） | 路由 |
| `prefers-reduced-motion` | 关闭惯性与过渡动画（直接跳位） | 全局 |

**焦点书**定义：`θ` 最接近"正前方向"（图中为屏幕正下方，即 `+90°`）的那一本；焦点书显示标题/作者/进度信息（展示形式【待你确认】）。

## 4. 内容与数据契约

```ts
// M14 内部契约（不是 IPC 契约，可 mock）
export interface HomeBook {
  documentId: number;
  fileName: string;
  title: string;              // 优先 pdfTitle，回退去扩展名的 fileName
  author: string | null;
  spineColor: string;         // 预设色板取色：hash(documentId) % palette.length
  pageCount: number | null;
  progress: { pageNo: number } | null;   // 来自 DocumentDto.progressPage（R20）；**仅用于排序/悬停提示，不画在书脊上**（D12）
  textState: TextState;       // **不渲染任何标记**（D12）——仅用于决定该书是否可被全局搜索命中时的提示
}

export interface HomeDataSource {
  load(): Promise<HomeBook[]>;   // 首版：document_recent(limit) 失败则回退 document_list
}
```

数据源规则（首版）：

1. 默认取`最近阅读`（`document_recent`，limit【待你确认】）；不足时用 `document_list`（按 added 倒序）补齐。
2. 全部为空 → 空态：**不渲染环**，在环心位置显示一句「还没有文献」+ 一个【添加文献库】按钮（D14 已定）。点击后调系统目录选择器 → `library_root_add` → 触发首次扫描。
3. `N = 1` → 单本居中直立于正前，不旋转；`N = 2` → 两本对称分列；`N ≥ 3` → 进入环模型。
4. mock 分支必须有明确标记 `__MOCK__`，真实接口就绪后**删除**，不得长期保留。

## 5. 性能边界（可验收）

| 指标 | 门槛 | 测法 |
|---|---|---|
| 同时挂载的书脊 DOM 数 | `≤ ceil(visibleArc/360 × N) + 2` | `document.querySelectorAll('[data-home-spine]').length` |
| 拖拽时主线程长任务 | 无 > 16ms 的长任务（N=60、1920×1080） | Performance 面板 / `PerformanceObserver` |
| 拖拽帧率 | ≥ 55fps（N=60） | rAF 采样 3 秒 |
| 旋转不触发 React 重渲染 | 拖拽过程中 React 组件的 render 次数 = 0（用 rAF + CSS 变量/media transform 直接改 DOM） | 加计数断言 |
| 首次进入主页可交互时间 | < 300ms（N ≤ 60，无网络依赖） | 手工打点 |

## 6. 与整体布局的关系

- 主页是**入口**路由（`home`），不是阅读器的前置弹窗；与 `library`（列表视图）、`reader`、`settings` 平级。
- 从主页进入阅读：`opening` 过渡 = **书脊沿自身长轴抽出并放大，220ms 后切到阅读器**（D10 已定）。过渡中不得请求 PDF（拿到 documentId 后即可并行发起 `document_url`，但视觉上等过渡结束再挂载 reader）。
- 从阅读器返回主页：保留上次 `ringRotation` 与聚焦书（会话内），不重新计算初始角度。
- 主页不承担文献库管理职责（增删库根、批量操作在 `library` 视图）。

## 8. M14 验收标准（在 §7 未确认前，只验收结构部分）

1. `N = 0 / 1 / 2 / 12 / 60` 五档均不崩、不重叠成糊、可键盘操作。
2. 隐藏弧段 DOM 数为 0（用 `data-home-spine` 计数验证）。
3. 拖拽 3 秒期间无 React 重渲染、无 >16ms 长任务、≥55fps（N=60）。
4. 旋转离开再回到同一角度，书脊位置确定一致（无累积漂移：角度对 `2π` 取模）。
5. `prefers-reduced-motion` 下无惯性动画。
6. 数据源为空时走空态，不渲染空环。
7. `HomeDataSource` 可在 mock 与真实实现间切换，切换只改一处工厂函数。
8. 交付时列出 §7 十条的当前实现取值与待确认问题。
