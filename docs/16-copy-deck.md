## 5. 确认框（应用内浮层，不用系统原生弹窗）

| 触发 | 标题 | 正文 | 主按钮 / 次按钮 |
|---|---|---|---|
| 删除文献记录 | 删除这条记录？ | 只从文献库移除，磁盘上的文件不会被删除。阅读进度与书签会一并删除。 | 删除记录 / 取消 |
| 移除文献库根 | 移除这个文献库？ | 不会删除磁盘上的任何文件。可用【添加文献库】重新加入。 | 移除 / 取消 |
| 更改文献库 | 更改文献库 | 只改显示名。要换文件夹请用【替换】—— 换文件夹等于换内容，旧的文献记录必须一并清除。 | 保存 / 取消 |
| 替换文献库 | 替换文献库 | 把《{name}》指向新的文件夹。该文献库下现有的文献记录会被全部删除（索引、书签、阅读进度一并清除），磁盘上的原文件不会被删除。替换后会自动扫描新文件夹。 | 替换 / 取消 |
| 重建全部索引 | 重建全部索引？ | 现有索引会被清空并重新建立，期间搜索结果不完整。文献较多时可能需要较长时间。 | 开始重建 / 取消 |
| 删除书签 | 删除这个书签？ | — | 删除 / 取消 |
| 从备份恢复 | 从备份恢复？ | 当前数据库会被替换，恢复后无法撤销。建议先导出当前数据库。 | 恢复 / 取消 |
